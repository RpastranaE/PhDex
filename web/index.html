Actualizar y buscar

PhDex consulta las versiones de GitHub al iniciar el ejecutable. Puedes activar o desactivar la instalación al inicio en Actualizaciones. Si ya estás preparando un lote, terminarás primero y podrás actualizar con el botón. La copia del ejecutable anterior se guarda a su lado; los datos de Documentos se conservan. En Historial, escribe un nombre, ID, descripción o ruta en el buscador; los resultados se filtran mientras escribes.

Novedades para preparar un lote

En el primer paso puedes cambiar la carpeta de entrada, revisar pendientes o arrastrar archivos. El arrastre copia a Entrada sin sobrescribir. Para archivos que ya estén allí usa Revisar entrada. Las carpetas y adquisiciones con auxiliares se añaden completas con el selector.

Al añadir un archivo, PhDex busca fechas AAAA-MM-DD, IDs como CAR-27 y técnicas habituales. No lee el contenido. Acepta las sugerencias que encajen; si hay varios IDs o fechas, elige manualmente. Un nombre completo válido se conserva mediante el campo Nombre manual, que puedes vaciar para reconstruirlo.

En Reglas de clasificación vincula nombres con tus plantillas. Usa + Añadir condición para combinar textos, extensión, Empieza por, Termina en o No contiene. Todas (Y) exige cada condición: por ejemplo, Contiene DRX + Extensión csv. Cualquiera (O) acepta alternativas: Contiene DRX + Contiene XRD. Un texto por fila; hasta 20 condiciones. Las reglas anteriores se conservan. Si coinciden varias reglas tendrás que elegir. Los cambios de reglas se aplican a archivos añadidos después, y no alteran los que ya hayas revisado.

Mientras completas datos verás el nombre resultante. La revisión final comprueba además el destino y las colisiones. Al terminar, selecciona los destinos y pulsa Abrir seleccionados: no se abrirán automáticamente.

Modo rápido: tu recorrido habitual

  1. En Plantillas y favoritos, crea una plantilla con carpeta, tipo, registro y técnica habituales. También puedes guardar solo una carpeta como favorito. Puedes editar o quitar estos accesos sin tocar los archivos.
  2. En Nuevo lote, elige los archivos y pulsa Siguiente. Para cada uno, selecciona una plantilla o un favorito, escribe el ID y ajusta la descripción. Si la plantilla ya tiene descripción, puede bastar con el ID.
  3. La fecha inicial es hoy; se muestra en la fila. Cambia fechas anteriores en Fecha y más opciones. Las plantillas no guardan ID ni fecha, ni confirman RAW automáticamente.
  4. Pulsa Siguiente: revisar, comprueba nombres y rutas y exporta. Los originales se conservan y las colisiones bloquean la copia.

Un favorito solo cambia la carpeta. Elegir una plantilla aplica sus datos al archivo elegido; revisa el ID que ya tuviera. Cambiar los datos de un archivo no modifica la plantilla guardada. Si prefieres escribir el nombre, despliega Escribir directamente el nombre completo: usa AAAA-MM-DD_ID_Descripcion sin extensión; ese nombre sustituye ID, fecha y descripción al exportar. Para otros casos puedes elegir Formulario completo.

Formulario completo

  1. Archivos. Pon tus archivos en D:\Doctorado\00_Entrada, pulsa Revisar Entrada y marca los que quieras. También puedes elegir archivos de otra ubicación.
  2. Datos. Rellena directamente la fila de cada archivo: tipo, registro, ID, fecha y descripción. Los campos adicionales se despliegan en esa misma fila. La edición conjunta es opcional y solo se aplica a las filas y campos marcados.
  3. Destino. Haz clic en el campo de carpeta para elegir una existente. + Añadir carpeta permite escribir un nombre y crearla al momento. Solo las carpetas nuevas de esa sesión y vacías muestran la opción de eliminarse. Pulsa Siguiente para revisar los archivos.
  4. Revisar. Comprueba los nombres y las rutas completas. Corrige los avisos de error y pulsa Exportar lote.

¿Qué significa copiar una carpeta entera?

Se copia la carpeta con todas sus subcarpetas y archivos como una unidad. No se renombran los archivos interiores. Úsalo para adquisiciones de equipos que necesitan varios archivos juntos. Para un PDF o un CSV suelto, usa Seleccionar archivos.

Dos detalles útiles

Réplica: otra adquisición. Versión: otra edición del mismo documento o análisis. Usa 0 si no quieres ese sufijo.

Al exportar se conservan los originales. Para volver a procesarlos, elige otro nombre o destino si la salida ya existe. Si usas Drive, comprueba allí que haya terminado de sincronizar.

La auditoría es una revisión de solo lectura: señala nombres y ubicaciones a revisar. Cerrar la última pestaña apaga la app; si hay una copia en curso, primero termina.
